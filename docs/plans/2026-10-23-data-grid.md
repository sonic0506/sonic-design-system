# DataGrid 작업 계획 (TanStack Table + dnd-kit)

목표: 정렬·선택·고정·드래그가 필요한 목록 화면에 쓰는 `DataGrid`를 Core에 추가해요.
TanStack Table(headless)로 상태를 다루고, 그리는 건 기존 `Table` 컴포넌트와 Sonic 컴포넌트로 해요. 그래서 셀 모양 구현은 Table과 하나예요.

## 0. 결정 사항

### 정한 것

| 결정 | 내용 | 이유 |
|---|---|---|
| 라이브러리 | `@tanstack/react-table` · `@tanstack/react-virtual` · `@dnd-kit/core` · `@dnd-kit/sortable` (모두 MIT) | 유료 버전이 없고, headless라 Figma 그대로 그릴 수 있어요 |
| 계층 | **Core** (`src/components/data-grid/`), 일반 dependencies, 메인 진입점에서 export | Base UI처럼 내부 구현 라이브러리예요. 쓰는 쪽은 설치하지 않고, 쓰지 않으면 번들에 들어가지 않아요(preserveModules). 앞서 이야기한 Adapter 계층과 서브 경로는 필요 없어져요 |
| 공개 API | 우리 props(`columns`, `rows` …)로 감싸고 TanStack 타입은 드러내지 않아요 | CLAUDE.md "Base UI 타입을 드러내지 않아요"와 같은 원칙이에요. 라이브러리를 바꿔도 쓰는 쪽 코드는 그대로예요 |
| Table과의 관계 | **모양은 Table, 동작은 DataGrid.** Table 컴포넌트에 상태별 모양(`sort`, `selected`, `dragging`, `pinned`)만 추가하고, DataGrid는 TanStack·dnd-kit으로 상태를 다루며 Table로 그려요 | 셀 모양 구현이 하나예요. 간단한 표는 의존성 없이 그대로 가볍게 써요 |
| Figma 구성 | 상태는 기존 `Table Cell`(`65:3742`)에 variant로 추가해요(코드의 Table 확장과 같음). 셀 내용 타입만 새 세트 `Data Grid Cell` | Figma 구조 = 코드 구조 |

## 4. 코드

### 공개 API (초안)

```tsx
<DataGrid
  aria-label="API 키"
  rows={keys}
  getRowId={row => row.id}
  columns={[
    { field: 'name', header: '이름', type: 'text', pinned: 'left', sortable: true },
    { field: 'requests', header: '요청 수', type: 'number', sortable: true },
    { field: 'status', header: '상태', type: 'badge', tones: { active: 'success', revoked: 'danger' }, labels: { active: '활성', revoked: '폐기됨' } },
    { field: 'createdAt', header: '만든 날', type: 'date' },
    { field: 'enabled', header: '사용', type: 'switch', onChange: (row, on) => toggle(row.id, on) },
    { id: 'actions', type: 'actions', pinned: 'right', actions: [
      { label: '이름 바꾸기', icon: Pencil, onClick: rename },
      { label: '삭제', icon: Trash2, tone: 'danger', onClick: confirmDelete },
    ] },
  ]}
  selection={selected} onSelectionChange={setSelected}        // 넘기면 체크박스 열
  onColumnOrderChange={setColumnOrder}                         // 넘기면 컬럼 이동
  onRowOrderChange={(ids) => saveOrder(ids)}                   // 넘기면 행 이동 핸들 열
  loading={isLoading}                                          // Skeleton 행
  emptyState={<EmptyState title="API 키가 없어요" action={…} />}
  errorState={error && <ErrorState title="API 키를 불러오지 못했어요" onRetry={refetch} />}
/>
```

- `columns`는 `type`으로 구분되는 union 타입이에요. `type: 'badge'`면 `tones`가, `type: 'actions'`면 `actions`가 타입으로 강제돼요
- 정렬·선택·컬럼 순서는 제어/비제어 둘 다 돼요(`sorting`/`defaultSorting` …)
- 가상 스크롤은 행이 많을 때 자동으로 켜져요(높이는 부모가 정해요)
