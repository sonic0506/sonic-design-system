# Patterns

Core 컴포넌트를 조합한, 도메인을 모르는 컴포넌트를 두는 곳이에요. 지금은 비어 있어요.

## 승격 기준 (Domain → Pattern)

아래를 모두 만족할 때만 프로젝트의 컴포넌트를 여기로 옮겨요.

1. **두 번째 프로젝트에서 같은 형태를 복사하게 됐다.** 한 프로젝트에서만 쓰면 승격하지 않아요.
2. **도메인을 모른다.** props에 `User`, `Order` 같은 도메인 타입이 없고, 데이터를 직접 불러오지 않고, 비즈니스 규칙이 없어요. 있으면 그 부분을 props로 빼낸 뒤에 옮겨요.
3. **Core만 조합한다.** 새 색이나 새 간격이 필요하면 먼저 Figma와 DESIGN.md를 고쳐요.

## 승격 순서

1. Figma Patterns 페이지에 컴포넌트를 만들어요(속성 이름 = props 이름).
2. DESIGN.md §10에 스펙, §11에 매핑을 추가해요.
3. `src/patterns/<name>.tsx`로 옮기고 `src/index.ts`에서 export해요. 테스트 1~2개를 추가해요.
4. 원래 프로젝트들은 패키지 버전을 올린 뒤 로컬 복사본을 지워요.
